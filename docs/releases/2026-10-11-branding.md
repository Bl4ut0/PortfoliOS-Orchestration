# PortfoliOS branding and login presentation

Published OS revision [d7a36db](https://github.com/Bl4ut0/PortfoliOS/commit/d7a36db), release `2026.10.11.5`.

The Desktop login header and workspace brand use the established white-chevron/cyan-cursor `>_` mark. Boot and the favicon retain that mark. The public account is labeled “PortfoliOS public profile,” with Bl4ut0 portfolio context and a contained, padded portrait. Desktop login uses semantic OS surfaces; Mobile retains its phone presentation.

Validation: OS app/session/security checks and staged startup browser checks passed. The production deployment uploaded ten selected assets; all ten live SHA-256 hashes matched local files. Disposable Chrome contexts verified the live Desktop mark and Desktop/Mobile public label and portrait sizing. No Google account credentials were used.

This scoped release does not certify the additional Craft adapters, automatic editor saves during account switching, or VS Code integration. Their broader review remains outstanding; preliminary source inspection found that the six new Craft adapters do not yet handle save messages or update their dirty-state flags.
