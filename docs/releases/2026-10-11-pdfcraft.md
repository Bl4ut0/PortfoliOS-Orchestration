## Delivered behavior

The Desktop adapter loads the unmodified official PdfCraft 0.6.0 engine on opening, imports scanned PDFs and saves editor outputs to profile-scoped SystemFS. Dirty edits, failed saves and pending writes guard close/profile switching. Failed exports can retry. The sandbox has no same-origin privilege or OS storage/token access; selected bytes cross a validated owned-frame bridge. Public installation/files reset on reload. The Mobile Store lists Desktop availability; native phone editing remains future work.

- Real PdfCraft WASM browser check locally and on production: Store install, zero engine requests during boot, opaque frame, original generated PDF import, persistent 90-degree page rotation, dirty close/switch vetoes, failed-write retry, scanned Save output, owned-frame spoof rejection, teardown/reopen, private A/B separation and public reload reset. No real Google account, private document or access token was used.
- Official archive importer restored and validated its SHA-256 and every receipt-listed file. Orchestration passed 10 tests including missing/changed artifact deployment rejection.

## Deployment and production evidence

The checksum-verified targeted deployment uploaded 52 files, 39.43 MiB, with referenced assets before the OS entry point. Production returned build `2026.10.11.1`. Runtime HTML (1,210 bytes), JavaScript (162,788 bytes) and WASM (40,599,741 bytes) matched their exact receipt SHA-256 values over the PHP gateway. Public runtime headers returned `Access-Control-Allow-Origin: *`, `Cross-Origin-Resource-Policy: cross-origin` and no X-Frame-Options; the hosted real-engine test passed.

These checks certify the initial PDF workflow, not every PdfCraft tool, OCR/encryption behavior, physical phone performance, live Drive backup/restore or offline engine installation. PhotoCraft and VectorCraft remain separate next evaluations. Engine source is upstream; ignored restored runtime artifacts are deployed but are not committed to either repository.

## Native interaction follow-up: build 2026.10.11.2
